📱 Meta Ads: Closing the Attribution Loop

O Problema Hoje

  • Você sabe que anúncio → Lead (Lead form) ✓
  • NÃO sabe se esse Lead → Conta → WhatsApp → Pagante ✗
  • Métrica: CPL (não relevante)
  • Decisão: manda mais grana onde não sabe se funciona

O que Falta (Curto Prazo)

1. Sincronizar Lead → Conta no CAPI

Quando alguém abre conta, enviar event "CompleteSignup" pro CAPI. Meta daí consegue ligar Lead Form → Signup.

2. Evento "AtivouWhatsApp" no CAPI

Já está marcado no banco. Edge function que manda pro CAPI quando logs_conexao.criado_em.

3. Evento "Primeira Cobrança" no CAPI

Quando a primeira cobrança automática roda com sucesso, enviar event "Subscribe".

4. Dashboard de Atribuição

Query: Lead Form ID → contas.referrer_source → logs_conexao → primeira cobrança. Resultado: CAC real por channel e nicho.

Ferramentas a Montar

edge/meta-capi-events.js

Dispara CompleteSignup, AtivouWhatsApp, Subscribe pro CAPI na hora certa. Varia por event type.

Dashboard: /admin?aba=meta-attribution

Cards: Total gasto | Leads | Contas | WhatsApp | Pagantes | CAC final

Cronjob: daily-meta-metrics

Puxa insights do Meta API + dados Supabase, popula meta_daily_metrics para trending.

🔍 Google Ads: Capturar Intenção Alta

A Oportunidade

Meta interrompe alguém scrollando. Google responde quem tá procurando.

  • Pessoa busca "sistema para academia" → Mensalli pode aparecer
  • Pesquisa muito mais qualificada (80%+ bottom-of-funnel)
  • Ticket médio melhor do que Meta (menos tire-riders)
  • Keywords de intenção alta = melhor ROAS

Por Nicho (Fase 0)

Pilates / Yoga

  • sistema para estúdio de pilates
  • gerenciar alunos pilates
  • cobrança automática pilates
  • mensalidade estúdio

Academia / Luta

  • sistema para academia de musculação
  • academia de luta software
  • gerenciar membros academia
  • cobrança automática academia

Natação

  • sistema para escola de natação
  • gerenciar alunos natação
  • cobrança automática
  • software academia aquática

Multi-nicho

  • software para cobrar alunos
  • sistema de mensalidades
  • cobrança via WhatsApp
  • software academia online

Estrutura de Campanhas

Campanha 1: Pilates (CPA, $8-12/conta)

Landing: /lead/pilates | Keywords: sistema estúdio pilates, etc | Destination: trial com template Pilates pré-preenchido

Campanha 2: Academia de Luta

Landing: /lead/luta | Keywords: Academia luta software, BJJ, box, muay thai | Template: Academia/CT

Campanha 3: Natação

Landing: /lead/natacao | Keywords: Escola natação software, gerenciar alunos natação | Template: Natação

Campanha 4: Catch-all

Keywords genéricas | Destino: /app/signup com contexto "From Google"

Ferramentas a Montar

/lead/{nicho}

Landing pages simples: 1 headline nicho-específico, 1 CTA, form mínimo (email+tel), pre-fill trial.

Tracking: gclid na URL

Salvar gclid em contas.referrer_source quando ativa conta, ligar em dashboard.

Dashboard: /admin?aba=google-metrics

Gastos Google → Contas por nicho → CAC por nicho.

Cronjob: sync-google-analytics

Puxa performance de cada landing page, mostra taxa conversão.

📲 Outbound: Maior ROI, Menor Custo

A Premissa

  • 30 abordagens/dia = ~600 por mês = 2-3% conversão = 12-18 contas/mês
  • Custo: seu tempo + WhatsApp Business API (~R$50/mês)
  • Bônus: descobre exatamente o pitch que vende para cada nicho

Estrutura Operacional

3 Verticais (Fase 0)

Pilates, CTs/Academias de Luta, Escolas de Natação

Daily List: 30 contatos/dia

10 por vertical. Input: Instagram, Google Maps, WhatsApp Business, LinkedIn.

Pitch por Nicho (Template)

Pilates: "Oi! Vi que você gerencia [Studio Name]. Você usa algo pra gerenciar mensalidades e enviar cobranças pelo WhatsApp?"

Follow-up automático

Se não responde em 2d: "Oi! Só confirmando se recebeu a mensagem. Pode responder aqui!"

Ferramentas a Montar

Painel: /admin?aba=outbound

Agenda semanal (seg-sex 10-30 contatos). Log de cada contato: nome, vertical, link, status.

Script n8n: daily-prospecting-list

Roda 7h, cria 30 linhas (10 pilates, 10 luta, 10 natação) em Supabase. Usa Google Maps API.

API: /api/outbound/log

Registra cada contato abordado. Campo: vertical, telefone, resp/não resp, trial criado.

Automação n8n: follow-up

Cron 11h: se status="não respondeu" e age > 24h, manda mensagem follow-up pelo WhatsApp.

Tracking: referrer_source="outbound-{vertical}"

Quando cria trial, gravar origem. Dashboard mostra conversão por vertical.

Exemplo de Pitch por Vertical

Pilates:
"Oi! Vi que você gerencia o [Studio]. Você usa algo pra cobrar
mensalidade dos alunos e enviar cobrança automática pelo WhatsApp?
Temos um sistema que faz exatamente isso. Posso fazer uma demo rápida?"

Luta:
"E aí! Vi que você coordena o [CT/Academia]. Você usa sistema pra
gerenciar alunos, cobrar mensalidade e enviar lembretes?
Desenvolvemos uma solução exatamente pra academias e CTs. Bora ver?"

Natação:
"Olá! Vi que você é responsável pela [Escola de Natação].
Você tem algum sistema pra gerenciar alunos e cobranças?
Temos uma solução feita pra escolas. Quer conhecer?"

🎁 Programa de Referral: Rápido de Montar

Modelo Simples (Fase 0)

  • Cliente indica empresa A: ganha 1 mês grátis
  • Empresa A ativa WhatsApp + faz 1ª cobrança: referrer ganha desconto
  • Sem complexidade: sem múltiplos níveis, sem cashback

Parceiros Alvo (Fase 1)

Fitness (Naturais)

  • Consultores de academia
  • Instrutores de pilates/yoga
  • Gestores de tráfego (nicho fitness)
  • Influencers pilates/academia

Educação / Serviços

  • Contadores (assessoria academia)
  • Consultores de gestão
  • Agências locais
  • Professores de empreendedorismo

Fluxo Técnico

1. Gerar código referral único

/admin?aba=minha-conta → "Link de indicação" → copia código único (ex: REF-CAIO-ABC123)

2. Compartilhar link

Simples URL: mensalli.com.br?ref=REF-CAIO-ABC123 ou WhatsApp

3. Cadastro via ref (trial)

Alguém clica, cria trial → contas.referrer_code = "REF-CAIO-ABC123" (salvo no localStorage)

4. Ativar WhatsApp + 1ª Cobrança

Trigger: contas.conectado = true E primeira_cobranca.status = paga → users.referrer_credit = 1 (mês grátis)

5. Dashboard /admin?aba=meus-referrals

Mostra: indicações (10), ativadas (2), próximas a ativar (3), crédito em meses (2).

Banco de Dados

Tabela: referral_programs

id, user_id, referral_code, criado_em, ativo, descricao

Tabela: referral_conversions

id, referrer_user_id, referred_account_id, status (trial/ativado/pagou), criado_em

Coluna: usuarios.referrer_credit

Quantos meses grátis o usuário tem pendente (acumula por referral).

Ferramentas a Montar

/admin?aba=meus-referrals

Card com link copiável, dashboard de indicações, crédito restante.

Automação: on_primeira_cobranca

Se contas.referrer_code não vazio, UPDATE usuarios SET referrer_credit += 1

/admin?aba=parceiros (interno)

Você gerencia parceiros manuais: contador X referiu 5 (3 ativadas), crédito acumulado.

Email: Bem-vindo parceiro

Quando liga parceria, envia template com link único.
